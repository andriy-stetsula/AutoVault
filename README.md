# AutoVault

AutoVault is a car catalog built with Next.js and TypeScript.

## Features

- Browse cars from REST API
- Search cars by model
- View detailed car information
- Add reviews
- Save reviews in Local Storage
- Dark / Light theme
- Theme persistence after page reload
- Responsive design

## Technologies

- Next.js
- React
- TypeScript
- SCSS
- REST API
- Local Storage
